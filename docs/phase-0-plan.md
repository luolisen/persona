# Phase 0 执行计划

## 当前切片：独立环境准备

目标：提供可复现的专用 OpenClaw 安装、隔离启动入口与验证证据，为后续扫码准备环境。

开发 Work 的首轮交付：

- 读取冻结决策与本机已安装 OpenClaw 文档/代码，核实隔离配置方式。
- 实现项目专用入口与示例配置，运行数据、依赖与凭据被 Git 忽略；不复制现有账号资料。
- 验证实际配置/状态/工作区路径和端口隔离，增加有意义的防止误用默认实例的检查。
- 条件允许时安装专用 OpenClaw 与微信插件，核实版本兼容；网络受阻时记录精确失败，继续离线工作。
- 不实现 Character Runtime、Memory、World；不发送真实微信消息；不注册后台服务。
- 输出变更摘要、执行命令、检查结果、未完成项与可回滚方式。首轮不自行提交。

主 Work 验收：检查入口是否可能读取默认配置、修改现有实例、共享凭据或端口；复核测试与真实运行证据，再决定集成。

## 后续切片

1. 专用账号扫码及真实收发探测：测试联系人由用户明确指定后才发送。
2. 核验模型 API 与严格输出格式，不读取已有其他 agent 的密钥。
3. 输入聚合 → 一次模型调用 → 多消息动作 → 本地调度。
4. 插话中断、过期、失败、UNKNOWN、睡眠恢复验收。

通过标准：真实链路证据与模拟测试分别记录。模拟通过不能称为微信已验收。
