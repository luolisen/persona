# 独立环境验收要求

2026-09-16，主 Work 审计清单；当前尚未验收开发实现。

依据本机 OpenClaw 2026.7.1-2 的 `docs/gateway/multiple-gateways.md`：单独 profile 不足以证明全部隔离，必须核实显式工作区和派生端口。

## 必须取得的证据

- 实际可执行文件位于专用安装目录，不对全局安装执行更新或插件安装。
- 配置、state、workspace、插件、日志均解析到专用根目录，符号链接不能逃逸到现有实例。
- 调用者遗留的 OPENCLAW 环境变量不覆盖项目路径；不继承既有模型凭据、账号或 agent 路径。
- 网关仅监听 loopback，使用独立端口；如启用浏览器，验证 base+2 及 CDP 范围，不能只检查主端口。
- 不依靠 `gateway restart/install` 操纵已有系统服务；使用前台进程或可识别的专用进程。
- 配置验证、启动失败和清理不产生默认 `~/.openclaw` 路径写入。
- 测试证明隔离失败时拒绝执行，而非仅检查脚本文本包含变量名。
- 账号扫码与联系人消息测试另设真实验收记录；离线检查不宣称通道通过。

回滚以删除本项目生成的独立环境为边界；不得删除或重置现有 OpenClaw 数据。
